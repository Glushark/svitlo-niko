# Статус света — iPhone

## Загрузить полный сайт в GitHub Pages

1. Скачай ZIP-архив проекта и распакуй его.
2. Открой репозиторий `Glushark/svitlo-niko` на GitHub. Через **Add file → Upload files** загрузи содержимое распакованной папки в корень репозитория: файл `index.html` должен оказаться рядом с `app.js`, `styles.css` и папками `assets`, `icons`, `proxy`.
3. Подтверди загрузку кнопкой **Commit changes** и дождись зелёного статуса GitHub Pages.
4. Открой сайт заново. В новой версии есть закруглённое меню очередей, видеофон и обновлённый офлайн-кэш.

Файл `proxy/worker.js` в архиве — исходник API-прокси. Его не нужно загружать в GitHub Pages или повторно развёртывать в Cloudflare, если текущий Worker уже работает.

Это устанавливаемое веб-приложение (PWA) для iPhone. Оно использует те же публичные API и правила очередей, что и Windows-виджет.

Макет адаптируется к ширине экрана: на телефоне приложение располагается одной колонкой, на широком экране график открывается рядом с карточкой статуса. Звёздный фон и туманность медленно анимируются; при системной настройке уменьшения движения анимация отключается.

## Возможности

- выбор очереди из списка API;
- актуальный статус с цветным неоновым индикатором;
- следующий переход с объединением соседних одинаковых интервалов;
- исключение «Конец неопределённости» для двух и более жёлтых блоков перед зелёным;
- расписание за весь день с подсветкой текущего интервала;
- автоматическое обновление раз в минуту и ручная кнопка обновления;
- светлая, тёмная и системная темы;
- последний загруженный график остаётся на экране без сети, с отметкой о его давности.

## Установка на iPhone

Папку нужно разместить на HTTPS-хостинге: iOS устанавливает веб-приложения с безопасного HTTPS-адреса. Затем откройте адрес в Safari, нажмите «Поделиться» → «На экран Домой» и подтвердите установку.

Для чтения публичного API используется небольшой Cloudflare Worker-прокси, потому что GitHub Pages не может обойти ограничения CORS сайта. Адрес уже настроенного Worker включён в `app.js`, поэтому вручную вводить его в приложении не нужно. Исходник прокси находится в `proxy/worker.js`; он разрешает запросы только с адреса этого приложения и только к трём фиксированным API-адресам.

## Подключить прокси для API

1. Сначала обнови файлы приложения в GitHub-репозитории версией с этим разделом настройки.
2. В Cloudflare открой **Workers & Pages** → **Create application** → **Create Worker**. Задай имя, например `svitlo-niko-api`, и создай Worker.
3. Нажми **Edit code**, замени демонстрационный код содержимым файла `proxy/worker.js`, затем нажми **Deploy**. Cloudflare покажет HTTPS-адрес вида `https://svitlo-niko-api.<твой-поддомен>.workers.dev`.
4. Адрес Worker уже указан в приложении автоматически. Поле в разделе **«Настройка подключения API»** нужно только если Worker был пересоздан и получил новый адрес.

Интерфейс Cloudflare может немного отличаться; актуальная инструкция: https://developers.cloudflare.com/workers/get-started/dashboard/.

## Данные

Используются публичные endpoints `off.energy.mk.ua` для расписания, активных изменений и списка очередей. Время отображается по часовому поясу телефона.
